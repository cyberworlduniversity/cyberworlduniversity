## 👋 About

Cyber World University (CWU) is a technology and cybersecurity education initiative focused on practical learning, cybersecurity awareness, ethical hacking, secure software development, and digital safety.

This GitHub space is used to document projects, experiments, educational resources, security research, and open-source work.
